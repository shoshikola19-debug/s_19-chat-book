# S_19 CHAT BOOK

হোয়াটসঅ্যাপের মতো ফ্রি মেসেজ আর ভয়েস কলের অ্যাপ — বাংলা ইন্টারফেস। একটাই
Node.js + Express সার্ভিস; ফ্রন্টএন্ড একই সার্ভার থেকে আসে। ডেটাবেস:
`DATABASE_URL` সেট থাকলে Postgres (Neon, ফ্রি টিয়ার), না থাকলে লোকাল
SQLite ফাইল। Render ফ্রি টিয়ারে চালানোর জন্য তৈরি।

## যা যা আছে

- **লগইন (৩ ধাপ):** ফোন নম্বর বা Gmail — যেকোনো একটা দিয়ে। ফোনে
  দেশ বেছে নেওয়া (২৪৮টি দেশ, বাংলাদেশ +880 সবার আগে), নম্বর, ৬ সংখ্যার
  কোড; Gmail-এ ঠিকানা, ৬ সংখ্যার কোড (ইমেইলে আসে, ফ্রি); তারপর নাম।
  একবার লগইন করলে ওই ফোনে লগইন মনে থাকে — নতুন ফোনে বা লগ আউট করলেই
  শুধু আবার কোড লাগে। বন্ধু যোগ করা যায় নম্বর দিয়ে বা Gmail দিয়ে —
  পরিচয় হয় ফোন নম্বর অথবা Gmail ঠিকানা।
- **চ্যাট:** খালি ইনবক্স, উপরে খোঁজার ঘর, সবুজ + বোতামে নম্বর যোগ করে আলাদা
  ১-টু-১ চ্যাট, ডাবল টিক (✓✓ = পৌঁছেছে)।
- **ভয়েস কল:** WebRTC, কম ডেটার অডিও (Opus মনো ~16 kbps, নীরবতায় প্রায়
  শূন্য), মাইক বন্ধ, শেষ করা, টাইমার, নেট কেটে গেলে নিজে থেকে আবার জোড়া লাগে।
- **আপডেট:** স্ট্যাটাস (লেখা স্ট্যাটাস, যোগ করা বন্ধুরা ২৪ ঘণ্টা দেখে, তারপর
  নিজে থেকে মুছে যায়, নিজেরটা মুছা যায়, বন্ধুদেরটা সবুজ রিংসহ, পুরো পর্দায়
  দেখা যায়) আর চ্যানেল (যে কেউ বানাতে পারে, নাম/বিবরণ দিয়ে সার্চ করে পাওয়া
  যায়, ফলো করলে নতুন আপডেটের সবুজ সংখ্যার ব্যাজ আসে, চ্যানেল খুললেই ব্যাজ
  মুছে যায়, শুধু মালিক পোস্ট করতে পারে)।
- **টুলস:** নিজের নাম/নম্বর, লগ আউট, আর দিনের আনুমানিক ডেটা খরচের মিটার
  (মেসেজ বনাম কল আলাদা করে) — লক্ষ্য সারাদিনে ৫–১০ MB।
- **কম নেটে চলে:** মেসেজ শুধু নতুনগুলোই নামে, নেট না থাকলে মেসেজ জমা থেকে
  নেট এলেই নিজে থেকে চলে যায়, ট্যাব লুকানো বা অফলাইন থাকলে পোলিং থামে।
- **লোগো:** মুকুটসহ S_19 লোগো — ওয়েলকাম পর্দায় বড় করে, হেডারে ছোট করে।

## লোকালভাবে চালানো (পরীক্ষা)

```bash
cd s19-chat-book
npm install
npm start
# খুলো: http://localhost:3000
```

টেস্ট মোডে লগইনের ৬ সংখ্যার কোড পর্দায় দেখা যায় (আসল SMS/ইমেইল এখনো
যুক্ত হয়নি)।

## Render ফ্রি টিয়ারে দেওয়া (আসল লিংক)

১. কোডটা GitHub-এ পুশ করো (নতুন রিপো, যেমন `s19-chat-book`)।
   `.env` আর `s19.db` কখনো পুশ করবে না — `.gitignore`-এ আছে।
২. [render.com](https://render.com) → **New +** → **Blueprint** → রিপো বেছে
   নাও। `render.yaml` পড়ে Render নিজে থেকে সার্ভিস বানাবে।
৩. ড্যাশবোর্ডে সার্ভিসের লিংক পাবে, যেমন
   `https://s19-chat-book.onrender.com` — এই লিংকটাই বন্ধুদের দেবে।
৪. মনে রাখবে: **ফ্রি টিয়ারে Render-এর ডিস্ক মুছে যায়** — তাই ডেটাবেস
   আলাদা রাখতে হয়। Neon-এ ফ্রি Postgres প্রজেক্ট খুলে (কার্ড লাগে না)
   তার কানেকশন স্ট্রিংটা Render ড্যাশবোর্ড → সার্ভিস → **Environment**-এ
   `DATABASE_URL` নামে বসাও (নিচে "স্থায়ী ডেটাবেস" দেখো)। সেটা না করলে
   অ্যাপ SQLite ফাইলে চলবে, আর রিস্টার্ট/রিডিপ্লয়ে চ্যাট ইতিহাস মুছে যাবে।
৫. ফ্রি সার্ভার ১৫ মিনিট কেউ না ঢুকলে ঘুমিয়ে যায়; প্রথমবার খুলতে প্রায়
   ১ মিনিট লাগতে পারে। সবসময় জেগে থাকা চাইলে Starter প্ল্যান ($৭/মাস)।

## আসল SMS কোড যুক্ত করা

সার্ভারে SMS ভেরিয়েবলগুলো সেট করলেই কোড আর পর্দায় দেখাবে না — আসল SMS
যাবে। Render ড্যাশবোর্ড → সার্ভিস → **Environment**-এ এগুলো বসাও:

| ভেরিয়েবল | মান |
|---|---|
| `SMS_PROVIDER` | `amarsms` বা `cloudwave` |
| `SMS_API_URL` | গেটওয়ের SMS পাঠানোর ঠিকানা (ড্যাশবোর্ড থেকে) |
| `SMS_API_KEY` | গেটওয়ের API চাবি (কখনো গিটে দেবে না) |
| `SMS_SENDER_ID` | যেমন `S_19` |

বাংলাদেশি গেটওয়ে (উদাহরণ): Amar SMS — OTP ৳০.৩৫/SMS, ১০টা ফ্রি টেস্ট
SMS; CloudWave — ৳০.৩০/SMS থেকে, ছোট প্যাকেজ ৫০ SMS (মোট ৳১৭.৫০)।
গেটওয়ের অ্যাকাউন্ট খুলে বিকাশ/নগদে টাকা ভরতে হয়। প্রতি SMS-এর টাকা
পাঠানোর পক্ষ (অ্যাপের মালিক) দেয় — কোড যে পায় তার কিছু কাটে না। একবার
লগইন করলে লগইন মনে থাকে, তাই একজনের জন্য সাধারণত একটাই SMS লাগে।

## আসল ইমেইল কোড যুক্ত করা (Gmail লগইন)

Gmail-এ কোড গেলে টাকা লাগে না — ইমেইল ফ্রি। সার্ভারে ইমেইল
ভেরিয়েবলগুলো সেট করলেই কোড আর পর্দায় দেখাবে না — আসল ইমেইল যাবে।
Render ড্যাশবোর্ড → সার্ভিস → **Environment**-এ এগুলো বসাও:

| ভেরিয়েবল | মান |
|---|---|
| `EMAIL_PROVIDER` | `resend` বা `generic` |
| `EMAIL_API_URL` | ইমেইল পাঠানোর ঠিকানা, যেমন `https://api.resend.com/emails` |
| `EMAIL_API_KEY` | প্রোভাইডারের API চাবি (কখনো গিটে দেবে না) |
| `EMAIL_FROM` | পাঠানোর ঠিকানা, যেমন `S_19 CHAT BOOK <login@s19chatbook.app>` |

Resend-এর ফ্রি প্ল্যানে রোজ ১০০টা ইমেইল ফ্রি, কার্ড লাগে না — ছোট
অ্যাপের পরীক্ষার জন্য যথেষ্ট। `generic` দিলে যেকোনো JSON POST ইমেইল
API চলবে (api_key + from + to + subject + message)।

## স্থায়ী ডেটাবেস (Neon Postgres, ফ্রি)

Render ফ্রি টিয়ারের ডিস্ক মুছে যায় বলে লগইন/চ্যাট সার্ভার রিস্টার্টে
হারিয়ে যায়। স্থায়ী করতে ডেটাটা Neon-এর ফ্রি Postgres-এ রাখো:

১. [neon.tech](https://neon.tech) → Sign Up (কার্ড লাগে না) → New Project
   → নাম `s19-chat-book`, Region **Singapore** → Create project।
২. প্রজেক্টের ভেতরে মেনু (☰) → **Connect** → **Connection string**-এর
   নিচে `postgresql://...` লেখাটা কপি করো। এতে পাসওয়ার্ড থাকে — কখনো
   চ্যাটে বা গিটে দেবে না।
৩. Render ড্যাশবোর্ড → সার্ভিস → **Environment** → Add Environment
   Variable → KEY `DATABASE_URL`, VALUE ওই স্ট্রিংটা → Save। সার্ভিস
   নিজে থেকে রিডিপ্লয় হবে।
৪. সার্ভার চালু হলে লগে `DB: Neon Postgres` দেখাবে। `DATABASE_URL`
   না থাকলে আগের মতো SQLite ফাইলে চলবে (`DB: SQLite (local file)`)।

Neon-এর কানেকশন স্ট্রিংয়ে `channel_binding=require` থাকলে কোড সেটা
নিজে থেকে সরিয়ে দেয় (Neon-এর pooler এটা নেয় না) — আলাদা কিছু করতে
হবে না। Neon ৫ মিনিট না চললে ঘুমিয়ে যায়, তবে ডেটা থেকে যায়; প্রথম
অনুরোধে জাগতে ১–২ সেকেন্ড লাগতে পারে। ফ্রি প্ল্যান: প্রজেক্টে ১ GB
স্টোরেজ, মাসে ১০০ CU-ঘণ্টা কম্পিউট — এই অ্যাপের জন্য যথেষ্ট।

## নোটিফিকেশন (অ্যাপ বন্ধ থাকলেও কল/মেসেজ আসবে)

হোয়াটসঅ্যাপের মতো — ডেটা বা WiFi চালু থাকলে স্ক্রিন বন্ধ থাকলেও, অ্যাপ
বন্ধ থাকলেও কল আর মেসেজের নোটিফিকেশন আসবে। এটা Web Push (VAPID) দিয়ে
করা, ফ্রি — কোনো টাকা লাগে না।

**চালু করতে (একবারই):**
১. চাবি দুটো বানাও — এই প্রজেক্টে `npm install` করার পর একবার চালাও:
   `node -e "console.log(require('web-push').generateVAPIDKeys())"`
   দুটো চাবি আসবে: `publicKey` আর `privateKey`। প্রাইভেট চাবিটা
   `.vapid-private-key.txt` ফাইলে রাখা আছে (গিটে যায় না)।
২. Render ড্যাশবোর্ড → সার্ভিস → **Environment** → Add Environment
   Variable — দুটো বসাও: KEY `VAPID_PUBLIC_KEY` = পাবলিক চাবি, KEY
   `VAPID_PRIVATE_KEY` = প্রাইভেট চাবি → Save। প্রাইভেট চাবিটা কখনো
   চ্যাটে বা গিটে দেবে না — শুধু Render-এর VALUE ঘরে বসাবে।
৩. সার্ভার চালু হলে লগে `Push notifications: ENABLED (VAPID)` দেখাবে।
   চাবি না থাকলে লেখা থাকবে `disabled (no VAPID keys set)` — তখন
   নোটিফিকেশন ছাড়া অ্যাপ আগের মতোই চলবে।

**বন্ধুদের যা করতে হবে:** অ্যাপে লগইন করলে একটা ছোট ব্যাখ্যা দেখাবে —
"অনুমতি দাও" চাপলে Chrome নোটিফিকেশনের অনুমতি চাইবে, **Allow** দিতে
হবে। তারপর থেকে অ্যাপ বন্ধ থাকলেও কল/মেসেজের নোটিফিকেশন আসবে; চাপ
দিলেই অ্যাপ খুলবে। শর্ত: HTTPS হতে হবে (Render-এর লিংকেই HTTPS আছে),
আর ফোনে ডেটা বা WiFi চালু থাকতে হবে — স্ক্রিন বন্ধ থাকলেও চলবে।

**জেনে রাখো:**
- অনুমতি না দিলে (বা ব্রাউজার সাপোর্ট না করলে) কিছু ভাঙবে না — কল আর
  মেসেজ আগের মতো শুধু অ্যাপ খোলা থাকলেই আসবে।
- নোটিফিকেশনে মেসেজের লেখা যায় না — শুধু নাম আর "নতুন মেসেজ" / "কল
  আসছে…" দেখায়। আসল মেসেজ/কল অ্যাপ খুললেই আসে।
- কল এলে নোটিফিকেশনটা স্ক্রিনে আটকে থাকে (কেটে দিলে বা ধরলে তবেই
  যায়) আর ফোন ভাইব্রেট করে; মেসেজেরটা একটু পরে নিজে থেকে চলে যায়।
- Android Chrome-এ চলে; iPhone-এ Safari-তে ওয়েব পুশ শুধু হোম স্ক্রিনে
  যোগ করা অ্যাপে চলে।
